# FitLog - Gym Workout Tracker

FitLog is a clean and simple gym workout tracker built with Next.js, React, TypeScript, and Tailwind CSS.

## Features

- **Workout Library**: Browse workouts with search, muscle category filter, and sorting.
- **Workout Details**: View full details for any lift, including 4-step instructions and specifications.
- **Today's Plan**: Add up to 5 lifts to your daily routine, mark them as completed, or remove them.
- **Saved Workouts**: Save your favorite exercises to use whenever you want.
- **Local Storage**: Automatically saves your plan and saved lifts in your browser.

## How to Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
